#### Plier Wrench

A plier wrench uses the leverage of a long set of handles with serrated jaws on one end and a pivot directly behind the jaws to increase jaw strength and grip on the edges of a hex-nut. 

The pliers use a lever to increase the force applied to a hex-nut.
Force of hand X Distance from pivot = Force on hex-nut X Distance from pivot

The pliers work using simple leverage principles. Using a longer gripping handle and a shorter jaw, the user establishes a mechanical advantage that applies more force to the hex-nut that the user is putting on to it.

In statics we assumed that all pliers are rigid bodies and pivots as frictionless which allowed us to calculate torque and crimping forces.

Handle and jaw: smooth, long, handle used to establish mechanical advantage. Rigid jaw with grooves and teeth to grip onto bolts#####INSERT PHOTOS###

Center pin: holds both jaws together and provides a pivot point for the jaws. Absorbs shock and friction from the user.
