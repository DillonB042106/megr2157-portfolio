## Communicate

### Error propagation:
One crucial error I made was with feature D. I accidentally made it too short so it would not fit the beam once complete. I then had to go back and change the height and redo my calculations. I caught this error before moving on and it didn’t cause any later issues. 

### Assumption sensitivity:
I think I made the best choice with my material assumption. I do think that titanium would result in a more compact bracket if needed if money wasn’t a restriction. Aluminum would be more bulky but possibly the most cost efficient. I think that steel is the middle ground between the two choices.
